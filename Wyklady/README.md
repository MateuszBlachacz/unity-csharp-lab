# Przykłady z wykładów

Fragmenty kodu ze slajdów wykładów 1 i 2, po jednym pliku na slajd. Folder leży poza `Assets`, więc Unity go nie kompiluje: wiele fragmentów to wycinki metod, a nie całe klasy. Żeby uruchomić przykład, przepisz go do skryptu w `Assets/Scripts` (np. do metody `Start`).
